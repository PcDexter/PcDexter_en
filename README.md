**PCDEXTER V3.0** is an advanced Batch-based optimization engine designed to push Windows performance to its absolute limits. Unlike standard cleaners, it targets the **Windows Kernel**, **Network Stack**, and **Input Latency** to provide a 50%+ boost in system responsiveness.

---

## 🌟 Why PCDEXTER V3.0?
Traditional optimization scripts only delete temporary files. **PCDEXTER** rewrites how your system handles tasks:
* **Zero Latency Core:** Fine-tuned registry tweaks for Mouse & Keyboard response.
* **Kernel Optimization:** Advanced processor scheduling (Win32PrioritySeparation).
* **Network Stability:** Total elimination of Network Throttling for stable Ping.
* **Automated Diagnostics:** Built-in hardware detection tool.

---

## 🛠️ Optimization Modes

### 1️⃣ Extreme Mode (Latency Killer)
* **Target:** Competitive Gamers (PUBG, Valorant, CS2).
* **Action:** Disables Core Parking, sets Maximum CPU Priority, and kills visual overhead.
* **Result:** Maximum FPS and instantaneous input response.

### 2️⃣ Balanced Mode (Stable & Clean)
* **Target:** Creators, Students, and Daily Users.

## 🔒 Safety First
We value your system's stability. 
* **Restore Point:** Integrated option to create a system snapshot before any changes.
* **Rollback Utility:** A dedicated `PCDEXTER_ROLLBACK.bat` to revert all tweaks to Windows defaults in seconds.

## 🚀 How to Use
1.  **Download** the repository as a ZIP or Clone it.
2.  Right-click `PCDEXTER_V3.0.bat` and select **Run as Administrator**.
3.  Choose whether to create a **Restore Point**.
4.  Select your preferred mode and enjoy the performance!
---
## 📊 Technical Features
* **Win32PrioritySeparation:** Set to `26` for perfect foreground app scaling.
* **Network Throttling Index:** Set to `0xffffffff` to prevent Ping spikes.
* **Core Parking:** Fully disabled for 100% CPU readiness.
* **I/O Latency:** Registry tweaks for faster Disk/RAM data flow.
