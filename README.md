## 🛡️ The Security & Safety Manifesto
In an era of "black-box" optimization tools, **PCDEXTER** prioritizes transparency. We believe the user should have full control and knowledge of what happens to their system.

### 1. Transparent Open-Source Logic
PCDEXTER is written in **Batch (.bat)**. Unlike compiled `.exe` files, our source code is the file itself. Users are encouraged to:
* Right-click `PCDEXTER_V2.bat` -> **Edit**.
* Audit every single Registry key and Command.
* Verify that there are no external network calls or hidden data collection.

### 2. Native System Interaction
We strictly utilize **Windows Native Commands** (Reg, Sc, Powercfg, Taskkill). By avoiding third-party software, we eliminate the risk of malware, driver conflicts, or system instability.

### 3. Non-Destructive Methodology
* **No File Deletion:** We do not delete essential system files.
* **Reversibility:** Most tweaks focus on Windows Registry keys that can be toggled back if needed.
* **System Restore Recommended:** The script advises users to create a restore point, ensuring a safety net for all modifications.

## 🚀 Deep Dive: What PCDEXTER Does?

### ⚡ [BEAST MODE] - Zero Latency & Emulator Focus
Specifically tuned for **Competitive Gaming** and **Android Emulators** (GameLoop, BlueStacks, MSI).
* **CPU Priority:** Adjusts the kernel scheduler to prioritize active gaming processes.
* **Power Throttling:** Disables Windows Power Throttling to prevent CPU down-clocking during intense tasks.
* **GPU Scheduling:** Enables Hardware-Accelerated GPU Scheduling (HAGS) via Registry for compatible hardware.
* **Network Throttling:** Optimizes the Network Throttling Index to minimize ping spikes.

### 🥔 [POTATO MODE] - Legacy Hardware Revival
For systems with limited RAM (4GB-8GB) or older CPUs.
* **Aggressive Debloating:** Disables heavy background services like Print Spooler, Windows Search, and Maps.
* **Visual Optimization:** Disables transparency and window animations to free up GPU/RAM resources.
* **Service Stripping:** Stops non-essential "Telemetry" services that consume background CPU cycles.

### ⚖️ [HYBRID MODE] - Stability & Responsiveness
Designed for users who want a fast PC without losing Windows features.
* **Balanced Registry Tweaks:** Optimizes the Paging Executive to keep the kernel in RAM.
* **Input Lag Reduction:** Reduces "MenuShowDelay" and speeds up shell response.

### 🧹 [SMART CLEAN] - Privacy & Disk Health
* **Telemetry Removal:** Blocks Windows from sending usage data to Microsoft servers.
* **Deep Cache Cleaning:** Clears WinUpdate logs, Prefetch, and Temp files that accumulate over time.
